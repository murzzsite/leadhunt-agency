# Медиа Драйв — лендинг

Агентство: перехват целевого спроса конкурентов (звонки + заявки с сайтов + Авито) с первичной верификацией колл-центром из 250 операторов.

## Источник данных
- Голосовой бриф пользователя: перехват звонков/заявок конкурентов (в т.ч. Авито), колл-центр ~250 опытных менеджеров, цена 100–150 ₽.
- Реальное название бренда и логотип — «МЕДИА ДРАЙВ» — получены от клиента файлом с логотипом (img/logo.jpg) после первой версии сайта, заменили временное рабочее название LeadHunt везде по сайту.
- **Корректировка позиционирования от клиента (2026-09-15):** клиент прислал детальные правки — прежняя версия использовала слово «лид» в значении «готовый, прогретый клиент» за 100–150 ₽, что для B2B выглядит нереалистично и создаёт ощущение обмана. Переписали терминологию на трёхуровневую сетку:
  - **Raw-контакт (база)** — от 100 ₽ — номер телефона человека, проявившего активность у конкурента, без прозвона.
  - **Верифицированный контакт** — от 150 ₽ — перехват + экспресс-прозвон колл-центром (250 операторов), подтверждён живой человек и актуальный спрос.
  - **Квалифицированный лид (SQL)** — индивидуально, обычно от 500–1500 ₽ — клиент согласился получить именно коммерческое предложение.
  - Везде на сайте и в материалах слово «лид» в значении «готовый клиент» убрано, заменено на «контакт» / «верифицированный контакт». Добавлен отдельный блок «Что именно вы получаете» с честным объяснением (идентификация спроса → первичный фильтр → задача клиента закрыть сделку). Пример расчёта в презентации переписан — теперь явно показывает, что из 100 raw-контактов верифицируется в среднем 30–40.
